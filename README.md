# Лабораторная работа №2

## Объектно-ориентированные возможности языка Python

Лабораторная работа по дисциплине «Парадигмы и конструкции языков программирования».

Цель работы — изучить объектно-ориентированные возможности языка Python и реализовать классы геометрических фигур с использованием абстрактных классов, наследования, свойств и методов класса.

## Задание

Разработать консольную программу для работы с геометрическими фигурами.

Программа должна:

- содержать абстрактный класс геометрической фигуры с абстрактным методом вычисления площади;
- содержать класс цвета фигуры со свойством для чтения и изменения цвета;
- реализовывать классы прямоугольника и круга, наследующиеся от геометрической фигуры;
- реализовывать класс квадрата, наследующийся от прямоугольника;
- создавать объект класса цвета в конструкторах прямоугольника и круга;
- вычислять площади фигур, используя для круга константу `math.pi`;
- выводить параметры, цвет и площадь через метод `__repr__` с использованием `.format()`;
- хранить название каждой фигуры в поле класса и возвращать его методом класса;
- вызывать функцию внешнего пакета, установленного через `pip` в виртуальное окружение.

Каждый класс располагается в отдельном файле пакета `lab_python_oop`. Основной файл `main.py` находится в корне проекта.

Для варианта **N = 15** создаются:

- синий прямоугольник шириной 15 и высотой 15;
- зелёный круг радиусом 15;
- красный квадрат со стороной 15.

Дополнительное задание — проверить корректность работы программы с помощью модульных тестов.

## Требования

- Python 3; работа проверена на Python 3.12.3;
- Visual Studio Code;
- расширение Python от Microsoft;
- WSL с Ubuntu — при запуске проекта в среде WSL;
- внешний пакет `colorama` версии 0.4.6.

В программе используются стандартные модули `abc`, `math` и `unittest`. Пакет `colorama` обеспечивает цветной вывод в терминале.

## Открытие проекта в VS Code

1. Открыть папку проекта `PKYAP_Lab2` в Visual Studio Code.
2. При работе в WSL убедиться, что в левом нижнем углу указано `WSL: Ubuntu`.
3. Открыть терминал через меню «Терминал → Создать терминал».
4. Проверить версию Python:

```bash
python3 --version
```

5. Создать виртуальное окружение:

```bash
python3 -m venv .venv
```

6. Активировать окружение:

```bash
source .venv/bin/activate
```

7. Установить зависимости:

```bash
python -m pip install -r lab_python_oop/requirements.txt
```

8. Нажать `Ctrl + Shift + P` и выполнить команду `Python: Select Interpreter`.
9. Выбрать интерпретатор `.venv/bin/python` из папки проекта.

Команды приведены для Linux / WSL и выполняются из корневой папки проекта. В новом терминале перед запуском программы нужно снова активировать окружение.

## Запуск программы

```bash
python main.py
```

Для варианта **N = 15** ожидается результат:

```text

Вариант: 15

Прямоугольник: ширина = 15, высота = 15, цвет = синий, площадь = 225.00
```

## Вычисление площадей

| Фигура | Формула | Результат для N = 15 |
|---|---|---|
| Прямоугольник | `width * height` | `225` |
| Круг | `math.pi * radius ** 2` | приблизительно `706.86` |
| Квадрат | `side ** 2` | `225` |

Квадрат использует метод вычисления площади, унаследованный от прямоугольника. В его конструкторе сторона передаётся как ширина и высота через `super().__init__()`.

Площади вычисляются без округления. Два знака после десятичной точки задаются только при формировании строки в `__repr__`.
